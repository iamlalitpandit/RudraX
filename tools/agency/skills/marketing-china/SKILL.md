### Algorithm Priority
```
Completion Rate > Like Rate > Comment Rate > Share Rate
```

### Key Strategies

**Short-Video Content Planning**
- Golden 3-second hook → information density → ending cliffhanger
- Content matrix: educational, narrative/drama, product review, vlog
- Trending BGM, challenges, hashtags — weekly refresh
- Beat-synced cuts, subtitle rhythm, vertical 9:16

**Traffic Operations**
- DOU+ precision targeting (audience > money)

- Paid: Qianchuan ads, brand ads, search ads

**Livestream Commerce**
- Scene design, lighting, equipment checklist
- Script: opening hook → walkthrough → urgency close → upsell

- GPM, watch time, conversion rate tracking

**Video Script Template**
```
Seconds 1-3: Golden Hook (conflict/suspense/value/relatability)
Seconds 4-20: Core Content (pain → solution → demo → before/after)
Seconds 21-30: Wrap-Up (value statement + engagement prompt + series teaser)

**Content Mix**
- 40% Pillar: deep-dives, 10-20 min, high production
- 30% Trending: hot topic responses, meme integration
- 20% Community: Q&A, fan interaction, behind-the-scenes

**Content Strategy**
- 9-grid images: visual consistency, layout aesthetics
- Long-form Weibo/headline articles for deep-dive + SEO
- Short copy: golden phrases under 140 chars
- 3-5 posts daily covering peaks (8:00 / 12:00 / 18:00 / 21:00)
- Every post must include at least 1 hashtag

**KOL Partnership Pyramid**
```
Top-tier (awareness ignition) → Mid-tier (niche penetration) → Micro-KOC (grassroots credibility)

**Crisis Management — Golden 4-Hour Rule**

## 🔄 Agent Lifecycle States

Every agent operates in these states when managed by the Deputy Chief of Staff:

1. **IDLE** — Available for task assignment
2. **ASSIGNED** — Task dispatched, agent activated
3. **EXECUTING** — Agent working on task
4. **BLOCKED** — Waiting for dependency or clarification
5. **COMPLETE** — Task finished, reporting to Deputy + Chief of Staff
6. **REVIEW** — Output under quality gate review
7. **PASSED** — Quality gate cleared, output delivered
8. **FAILED** — Quality gate failed, needs rework or reassignment
